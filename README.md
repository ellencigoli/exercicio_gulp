# 🌟 Projeto Gulp + Sass

Este projeto é um exercício para praticar o uso de ferramentas como **Gulp** e **Sass** no desenvolvimento de um fluxo de trabalho eficiente. Ele inclui funcionalidades como compilação de **Sass**, minificação de arquivos **JavaScript**, e organização de **imagens**.

---

## 📋 Funcionalidades

- **Compilação de Sass**: Transforma arquivos `.scss` em `.css` com minificação.
- **Otimização de Imagens**: Organiza imagens na pasta de distribuição.
- **Minificação de JavaScript**: Reduz o tamanho dos arquivos `.js`.
- **Servidor Local**: Inclui um servidor local com live reload para desenvolvimento ágil.

---

## 🚀 Tecnologias Utilizadas

- **Gulp**: Automação de tarefas.
- **Sass**: Preprocessador CSS.
- **BrowserSync**: Servidor local com live reload.
- **Imagemin**: Organização de imagens.

---

## 🛠️ Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/ellencigoli/projeto-gulp.git
   ```
   ```bash
   cd projeto-gulp
   ```
2. **Instale as dependências:**
    ```bash
    npm install
    ```
3. **Execute as tarefas do Gulp:**
    ```bash
    gulp
    ``` 
4. Acesse o servidor local: O projeto será executado no endereço `http://localhost:3000` com live reload.    

---

## 📝 Tarefas do Gulp

As tarefas configuradas no gulpfile.mjs incluem:

- `styles`: Compila e minifica os arquivos Sass.
- `scripts`: Minifica arquivos JavaScript.
- `images`: Organiza imagens.
- `serve`: Inicia um servidor local e observa alterações nos arquivos.
